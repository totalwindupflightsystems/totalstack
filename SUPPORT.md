# Support

TotalStack is a development tool for local AWS cloud stack emulation. It extends LocalStack with 69 additional service providers generated via SpecLang.

## Getting Help

- **Documentation:** See `AGENTS.md` for architecture and development workflow
- **Issues:** Open a GitHub issue for bugs or feature requests
- **LocalStack upstream:** For LocalStack-core issues, see [LocalStack documentation](https://docs.localstack.cloud)

## Supported Services

TotalStack provides 69 AWS service providers on top of LocalStack's 40 core services. See `totalstack/providers.py` for the full registry.

## Requirements

- Docker 24+
- Python 3.13+
- LocalStack 4.14+
