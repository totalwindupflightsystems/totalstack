# Governance

TotalStack is a single-maintainer project. Governance is informal and lightweight.

## Decision Making

- The project maintainer (Bane/Lexi) has final say on all decisions
- Technical decisions are documented in specs and AGENTS.md
- Architecture changes go through SpecLang spec review

## Code of Conduct

See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## Contributing

See [CONTRIBUTING.md](CONTRIBUTING.md) for development workflow and commit conventions.

## Project Role

TotalStack is a coding-hermes managed project. The foreman handles task dispatch, quality gates, and continuous improvement. Human review is required for:
- Pushing commits (CI-003)
- Major architectural changes
- Dependency upgrades with breaking changes
