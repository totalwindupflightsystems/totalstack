# Acknowledgments

TotalStack is a fork of [LocalStack](https://github.com/localstack/localstack),
and it builds on the incredible work of the LocalStack team and community.

- **LocalStack** — the upstream project this repository is forked from.
  LocalStack provides a fully functional local AWS cloud stack for
  development, testing, and CI. See https://github.com/localstack/localstack
  and https://localstack.cloud for the original project, its license, and its
  maintainers.
- **LocalStack contributors** — everyone who has contributed code,
  documentation, issues, and reviews to the LocalStack project over the
  years.
- **AWS** — for the public service APIs and botocore service models that
  drive the spec-driven service implementations in this repository.

This fork maintains its own development process, spec pipeline, and test
suite; see [AGENTS.md](../AGENTS.md) and [README.md](../README.md) for how
TotalStack differs from upstream.
